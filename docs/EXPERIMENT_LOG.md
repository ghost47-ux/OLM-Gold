# Experiment log

All runs below use the **synthetic** XAU/USD fixture generated by OLM. No row here is real gold history, and none demonstrates a market edge.

## Environment

- Windows 11, AMD Ryzen 7 5825U (8C/16T), 15.37 GB RAM, CPU-only.
- Python 3.13.15, PyTorch 2.9.1+cpu, NumPy 2.5.5, pandas 3.1.1.
- Model: d_model 128, 4 transformer layers, 4 heads, d_ff 384, K=4 mixtures, **1,493,752 trainable parameters**.

## 2026-11-25 - synth90, 12 epochs (INVALID FOR EVALUATION)

- Data: 90 synthetic days, seed 7, 5,868 train / 1,253 validation / 1,254 test before the context-leak fix.
- Training: batch 64, 12 epochs, 1,104 optimizer steps, 1,238 s total, about 1.12 s/step and 57 samples/s.
- Final validation NLL: **-0.9841**; best checkpoint `synth90-20261125T161127Z-6a488bf6_best.pt`.
- Test: parent MAE 33.2383, child MAE 11.1758, CRPS 5.0588, coverage@50 0.7923, coverage@90 0.9926.
- **Why invalid:** H1/H4 context bars were selected by bar-open timestamp, so 100% of samples used an H1/H4 bar whose close was after the target start. This is lookahead leakage. The checkpoint and its report are retained only as a negative result and must not be promoted or quoted as forecast skill.

## 2026-11-26 - corrected point-in-time context, 1 epoch (SMOKE)

- Data: same 90 synthetic days after the fix; 5,857 train / 1,251 validation / 1,252 test. `leakage_check` reports **0 leaking H1 and H4 bars in every split**.
- Training: batch 64, 1 epoch, 92 steps, 131.08 s, 1.424 s/step, 44.9 samples/s, 4 PyTorch threads.
- Validation NLL: **5.3341** (parent 2.6126, child 2.6876). This is an underfit one-epoch model, not a converged result.
- Test: parent MAE 20.7253, child MAE 96.3164, CRPS 34.7597, coverage@50 0.9073, coverage@90 1.0000.
- Same test set, flat persistence: parent MAE **0.7034**, child MAE **0.4204**.
- **Conclusion:** the network trains and the leakage is fixed, but the one-epoch model is much worse than persistence and its intervals are over-wide. It is a pipeline smoke test, not a useful forecaster.
